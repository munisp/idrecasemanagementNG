# TX Auto Appraisal sector pack (v1.0.2026)

Texas SB 458 (effective 2026-01-01): mandatory binding appraisal in personal
auto and residential property policies. Clocks: 120-day demand window,
75-day appraiser negotiation, 180-day umpire award (property).

Determination: comparable evidence median (engine `comparable`).
Roster: TX licensed adjusters / I-CAR appraisers, 25+ completed appraisals.
